# Interster

Three.js (0.160.0, ESM / jsdelivr) を使ったインターステラー風ウェブサイト（3ページ構成：① トップ #p1 → ③ 5次元空間 #p3 → ④ 最終 #p4）。

※ ② 宇宙船ページは削除済み（#p2 のセクションとコードを削除。assets/image-2.png・ship-*.jpg は未使用のまま残している）。

- index.html : 全ページ・全シーンを含む本体
- assets/    : 元画像 image-1〜4.png と、そこから切り出した PC/スマホ用背景
- tools/make_backgrounds.py : 背景の再生成スクリプト（`python3 tools/make_backgrounds.py`、Pillow が必要）

- PC版 1600×900（16:9）、スマホ版 780×1688（iPhone 14 の 390×844 の 2 倍密度）。
- image-1 / image-3 は PNG 内の EXIF Orientation=8（実ピクセルは縦長）。書き出し時に回転を焼き込み済み。
- 元画像の UI 痕（image-1 右端の白帯、image-2 右下の白枠、image-4 上端の赤印）は切り出し時に除去。
- fifth-sp / last-sp は、正方向で縦に切ると約4倍拡大になるため、90°回転してから切り出している（中心消失点の構図なので回転しても成立する）。
- 元画像の解像度が低いため、どの背景も拡大になる（2倍超の拡大は軽くぼかしてジャギーを緩和）。高解像度の元画像があれば差し替え推奨。

## アニメーション（自動では動かない。すべてスクロール連動）
- 線・枠・背景画像・文字はすべて1実画素の粒子で描く。スクロール中は速度に応じて粒子が上へバラけ、止めると下へ落ちて元の形に戻る。
- 背景画像の粒子は `python3 tools/make_particles.py` で背景 JPG から生成（assets/particles/*.js。file:// でも読めるよう JS 形式）。背景を作り直したら再実行する。
- ① 2画面分（画面固定）。最初の半画面のスクロールで横線が文字（`SURFACE_TEXT`、仮の `INTERSTELLAR`）の形に盛り上がり、その後ブラックホールの光柱の付け根へ渦を巻いて吸い込まれる。
- ③ 重力波の波紋：スクロールした分だけ、奥の一点から球面状の波が手前へ進み、格子がたわむ。
- ④ 3画面分（画面固定）。スクロールで文字パネルが横にスライドし、格子と立方体が奥から手前へ流れ、カメラが左右に約±26度振れる。
  ③→④は、④が画面に入る量に応じて波紋が引き、流れに切り替わる。

## 実行
index.html をブラウザで開く（Three.js は jsdelivr CDN から読み込むためネット接続が必要）。

## 検証
`node tools/check.mjs [スクショ出力先]`（Playwright + Chromium が必要。手順はファイル冒頭のコメント参照）。
Chromium をダウンロードできない環境では `PW_CHANNEL=chrome` でインストール済みの Google Chrome を使える。
PC 1440×900 と iPhone 14 で、コンソールエラー・キャンバス描画・横スクロール・左右16px余白を確認し、各ページのスクリーンショットを保存する。
